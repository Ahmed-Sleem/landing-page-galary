Pattern 01 / AutomationRoutine → review

Repeatable work, with a visible stop.

A routine request moves forward by clear rules. An exception pauses for a person.

Pattern 02 / Context handoffGeneric system roles

Keep context moving between steps.

Connect a request, a shared record, an assistant, and a review point without naming vendors or assuming a particular stack.

Pattern 03 / AI assistantSource-aware first pass

Draft with context. Let a person decide.

Search approved material, prepare a source-linked draft, and wait for review before sharing.

Pattern 04 / IntegrationHandoff

Carry the useful detail.

Pass a status and next action between generic system roles so someone can pick up the work.

Pattern 05 / Human checkpointDecision gate

Make the stop visible.

Name the reviewer and the condition that calls for a human decision.

  • Surface decisions at the right time
